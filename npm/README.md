# homeplate (npm)

npm installer for [Homeplate](https://github.com/sikmabull/homeplate) — bring your runners home: your machine as your GitHub Actions CI.

```bash
npm install -g homeplate
homeplate auto
```

Downloads the correct prebuilt binary from the GitHub release and verifies its SHA-256.
macOS (arm64/x64) and Linux (arm64/x64). Prefer Homebrew? `brew install sikmabull/tap/homeplate`.
